# Evidencias del proyecto CeluMarket

Esta carpeta contiene las evidencias visuales y técnicas obtenidas durante la ejecución de las pruebas y verificaciones del proyecto CeluMarket.

## Organización prevista

- `funcionales`: capturas relacionadas con requerimientos funcionales RF01-RF12.
- `responsive`: evidencias de adaptación de la interfaz en diferentes resoluciones.
- `compatibilidad`: evidencias de funcionamiento en Chrome, Edge y Firefox.
- `rendimiento`: resultados visuales o técnicos relacionados con tiempos de respuesta.
- `compilacion`: evidencias del proceso de compilación y generación de la versión candidata.
- `publicacion`: evidencias de la aplicación publicada y accesible desde una URL externa.

## Convención de nombres

Las evidencias deberán incluir, cuando aplique:

- Código del requerimiento o caso de prueba.
- Tipo de evidencia.
- Versión del aplicativo.

Ejemplos:

- `RF01_navegacion_v1.0.png`
- `RF10_carrito_descuento_v1.0.png`
- `RNF01_catalogo_360px_v1.0.png`
- `RNF02_chrome_v1.0.png`
- `RNF03_rendimiento_catalogo_v1.0.png`
- `build_v1.0.png`
