# Formatos PMI diligenciados

Esta carpeta contiene las plantillas PMI de calidad diligenciadas con la información del proyecto CeluMarket.

Los documentos muestran la aplicación de los formatos oficiales suministrados por el tutor y deben mantenerse coherentes con el Plan de Gestión de Calidad y la versión del proyecto correspondiente.

- Quality Management Plan diligenciado.
- Quality Metrics diligenciado.
- Quality Audit - ejemplo simulado.
- Issue Log - ejemplo simulado.
