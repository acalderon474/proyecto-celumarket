# Pruebas del proyecto CeluMarket

Esta carpeta contiene los casos de prueba, registros de ejecución y resultados utilizados para verificar los requerimientos funcionales y no funcionales del proyecto CeluMarket.

## Organización

- `casos-prueba`: contiene los casos de prueba preparados o ejecutados.
- `resultados`: contiene resultados derivados de las ejecuciones, como reportes, archivos de texto, hojas de cálculo o registros técnicos.

## Trazabilidad

Cada caso de prueba deberá identificar como mínimo:

- Código de prueba.
- Versión o commit del aplicativo evaluado.
- Requerimiento funcional o no funcional relacionado.
- Responsable.
- Entorno de ejecución.
- Pasos o datos utilizados.
- Resultado esperado.
- Resultado obtenido.
- Evidencia asociada.
- Estado final Pass/Fail.

## Responsabilidad

QA será el responsable principal de coordinar, registrar y conservar las pruebas y sus resultados. DEV, AN, UX y otros roles participarán cuando corresponda según el tipo de verificación.
