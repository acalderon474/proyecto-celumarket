# Resultados de pruebas de CeluMarket

Esta carpeta contiene los resultados obtenidos durante la ejecución real de las pruebas funcionales, técnicas, de regresión, compilación y publicación del proyecto CeluMarket.

## Contenido

Los archivos almacenados en esta carpeta deberán corresponder a pruebas realmente ejecutadas y mantener relación con:

- El código del caso de prueba.
- El requerimiento RF o RNF evaluado.
- La versión o commit del aplicativo.
- La fecha de ejecución.
- El responsable de la prueba.
- La evidencia asociada.
- El resultado final Pass/Fail.

## Tipos de resultados

Podrán almacenarse, según corresponda:

- Archivos `.txt` con resultados de compilación, consola o pruebas automatizadas.
- Archivos `.csv` o `.xlsx` cuando una prueba genere resultados tabulares.
- Archivos `.pdf` cuando se genere un reporte consolidado.
- Otros archivos técnicos producidos directamente por las herramientas de prueba.

Las capturas de pantalla y evidencias visuales se conservarán en la carpeta `evidencias` del proyecto y deberán poder relacionarse con el caso de prueba correspondiente.
