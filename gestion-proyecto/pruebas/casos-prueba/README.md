# Casos de prueba de CeluMarket

Esta carpeta contiene las plantillas y registros utilizados para documentar la ejecución de las pruebas funcionales y no funcionales del proyecto CeluMarket.

Cada caso de prueba debe conservar trazabilidad con:

- El requerimiento RF o RNF evaluado.
- La versión o commit del aplicativo probado.
- El responsable de la ejecución.
- El entorno de prueba.
- Los pasos y datos utilizados.
- El resultado esperado.
- El resultado obtenido.
- La evidencia asociada.
- El resultado final Pass/Fail.
