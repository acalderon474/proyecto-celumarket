# Gestión del proyecto CeluMarket

Este directorio contiene la documentación de gestión, calidad, pruebas y evidencias del proyecto CeluMarket.

## Organización

- `calidad`: Plan de Gestión de Calidad y formatos utilizados.
- `pruebas`: casos y registros de pruebas del proyecto.
- `evidencias`: capturas, resultados y soportes obtenidos durante las verificaciones.

## Puntos de consulta

- QA: pruebas, métricas, evidencias e incidencias.
- GP: Plan de Gestión de Calidad, responsabilidades, decisiones y control de cambios.

## Control de versiones

Los documentos y evidencias almacenados en este directorio deberán conservar relación con la versión o commit del aplicativo evaluado.
